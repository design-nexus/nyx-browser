# Browser's site styles

Catppuccin userstyles (MIT) for common sites, and less.js (Apache-2.0) to compile them.
Each style is compiled with the current Nyx theme's colours mapped onto Catppuccin's
palette names, so when the theme changes the style does too.

Sources: https://github.com/catppuccin/userstyles · https://github.com/less/less.js
